🔒 Google Gemini API 보안 아키텍처

🛡️ 백엔드 서버 보안 연동 중

서버의 .env 파일에 암호화된 Google Gemini API Key가 저장되어 있어, 웹 브라우저나 네트워크 통신 상에 API 키가 절대 노출되지 않습니다.

GitHub Pages(정적 호스팅) 환경에서는 본인의 Google AI Studio 무료 API Key를 입력하여 실시간 시를 짓거나, 키 없이 데모 모드로 즐기실 수 있습니다.

🔗 Google AI Studio에서 무료 API Key 발급받기 →
🔒 보안 안내: 입력하신 키는 브라우저(LocalStorage)에만 보관되며 외부 서버로 전송되지 않습니다.

🛡️ 정보보안 지침 준수

  • ✅ Server-to-Server 통신: 백엔드 환경에서는 구글 API를 비공개 호출
  • ✅ 환경변수 격리 (.env): 소스 코드에 키를 하드코딩하지 않고 환경변수로 분리
  • ✅ Git 유출 차단 (.gitignore): 깃허브 커밋 시 .env 파일 원천 배제
  • ✅ Rate Limiting(속도 제한): 비정상적 다량 호출 및 DoS 공격 방지
